## Installation
1. Clone the repo:
   ```bash
   git clone https://github.com/loumgharihajar0-eng/heart-honeybee.git
   cd heart-honeybee
   ```
2. Install dependencies:
   - For Node:
     ```bash
     npm install
     ```
   - For Python:
     ```bash
     python -m venv venv
     source venv/bin/activate
     pip install -r requirements.txt
     ```
